# Development archive

`early-versions/` contains older C++ versions, including `PL_test.cpp`, which differs from the selected main version.

`experiments/` contains separate Java, JavaScript and C experiments.

The files are retained for historical reference; they are **not** necessarily independent, tested programs. `test.cpp` is byte-for-byte identical to `Project3.cpp` and is omitted. Original compiled executables and VS Code workspace settings are excluded.
